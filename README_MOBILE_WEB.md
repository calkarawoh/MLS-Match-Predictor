# MLS Match Predictor — Mobile Website Starter

This adds a responsive React website and a FastAPI backend to the existing Python project. It reuses `real_model.py` and `mls_live_data.py`; it does not replace the CustomTkinter desktop application.

## Important data/model requirements

- `data/mls_real_matches.csv` must exist and contain the completed match history used by `real_model.py`.
- `outputs/real_mls_model.joblib` must exist locally for predictions. It is intentionally excluded from Git by the existing `.gitignore`.
- If the model is missing, train it from the project root with `python real_model.py train`.
- `data/mls_live_snapshot.json` is a saved snapshot. The website displays that snapshot; this starter does not poll ESPN from a public endpoint.
- The ESPN feed in `mls_live_data.py` is unofficial and undocumented. Confirm the provider's terms, permitted use, and attribution before public deployment.

## 1. Install backend dependencies

Open PowerShell in the existing `MLS_Match_Predictor` project root:

```powershell
python -m pip install -r requirements-web.txt
```

If the real model has not been trained:

```powershell
python real_model.py train
```

## 2. Start the backend

From the project root:

```powershell
python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

Check the API at:

- http://127.0.0.1:8000/api/health
- http://127.0.0.1:8000/docs

## 3. Start the mobile website

Open a second PowerShell terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open the local URL Vite prints, usually http://localhost:5173.

## 4. What is connected

- Team list and recent form are built from `real_model.load_matches()` and `real_model.team_histories()`.
- Predictions call `real_model.predict()` and use the locally trained real-score model.
- Fixtures are read from `data/mls_live_snapshot.json`.
- `/api/reload` reloads local history/model files after a trusted local sync or retraining.

## 5. Refreshing data and model

The website does not automatically retrain the model. To update locally:

```powershell
python mls_live_data.py refresh
python real_model.py train
```

Then call `POST http://127.0.0.1:8000/api/reload` or restart the backend.

Do not expose an unauthenticated refresh/retrain endpoint on a public server.

## 6. Deployment

Deploy the frontend and backend separately after local testing. Configure `VITE_API_URL` to the deployed backend URL and set `FRONTEND_ORIGINS` on the backend to the exact deployed frontend origin(s). Train or provide the trusted model artifact on the backend host.

Do not publish API credentials, private data, or untrusted `.joblib` files. Only load model files generated by your own trusted training process.
